# PROLED Wallpaper

**The new MacBook Pro look. On your Mac.**

[See every Mac edition](https://github.com/ReffWu/proled-wallpaper#made-to-fit-your-mac) · [Interactive preview](https://reffwu.github.io/proled-wallpaper/)

## Your 5K display. Your finish.

- **Straight:** the original full rectangular 5120 × 2880 image, without an added corner mask.
- **Rounded:** four matching curves with pure black outside, using the same standard contour as the MacBook editions.

The four MacBook PNGs are unchanged. The earlier lower-corner-only 5K file is also included separately so existing download links keep working.

[Download all sizes and both 5K finishes](https://github.com/ReffWu/proled-wallpaper/releases/latest/download/proled-wallpapers-all-sizes.zip) · [Straight 5K PNG](https://github.com/ReffWu/proled-wallpaper/releases/latest/download/proled-mac-studio-5k-straight-5120x2880.png) · [Rounded 5K PNG](https://github.com/ReffWu/proled-wallpaper/releases/latest/download/proled-mac-studio-5k-rounded-5120x2880.png)

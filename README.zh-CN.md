把新款 MacBook Pro 的光影，带到你每天使用的 Mac。用纯黑圆角细致收边，也为外接显示器保留矩形满幅的 5K 直边版本。

- **顺滑一致的弧线。** MacBook 版处理底部两角，5K 圆角版处理全部四角。
- **弧线之外，都是纯黑。** 圆角版本去掉外侧多余灰色，边缘以细腻的像素过渡收尾。
- **适合你的屏幕。** 五种屏幕尺寸，5K 版另有直边、四角圆角两种外观。
- **无损 PNG，下载即用。** 保留现有母图细节，免费下载，无需安装 App。

## 更顺滑的圆角收边。

底部两侧沿同一条连续弧线对称收尾，轮廓外侧填纯黑，边缘细腻过渡。主体光影与纹理继续保留。

## 换个桌面，只需片刻。

1. 下载适合你 Mac 的 PNG 壁纸。
2. 在「**系统设置 → 墙纸**」中添加图片。
3. 换上新的桌面。
